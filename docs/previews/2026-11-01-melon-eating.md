# 西瓜：坐着吃西瓜

保持原本已坐在石台上的西瓜原画，不改变背景、猫伙伴、人物五官、衣着、资料卡或其他成员。只添加一个点击动作：举起怀中的瓜，吃两口、轻轻咀嚼，再放回怀里。连续点击排队，隐藏/离屏暂停，减少动态效果模式保持原图。

## 素材与方式

原图继续使用 `public/media/member-03-melon-profile.webp`，没有覆盖、降分辨率或重新压缩。手臂、手掌和瓜都裁取原图像素，在运行时分层绘制；肩部固定，肘部解算，手掌随瓜保持握持。脸和原坐姿不做整图拉伸。

使用内置 image_gen 编辑原画，补出被手臂和瓜挡住的黑色 T 恤与牛仔裤。仅将补画中的 x=270、y=522、325×132 区域无损保存为 `src/world-preview/assets/melon-lap-patch-v1.webp`（42,494 字节）。页面其他区域始终使用原图，不用补画替换整张背景。

最终素材提示词：以原画为编辑目标，相机、场景、头部、衣着、坐姿、猫和所有文字道具保持不变；去除西瓜以及黑色短袖以下的双手和裸露前臂，不补画放在腿上的手，补全其后方的黑色衣服、牛仔裤和局部环境；作为动画遮挡修补底图使用。第一次结果出现了放在腿上的手，第二次针对性去除后采用。

## 本地预览与验证

`/previews/member-portrait.html?member=melon` 连续播放，点击人物触发；追加 `&melonFrame=2` 或 `&melonFrame=3.65` 审查关键帧。预览参数仅开发环境启用。

`node scripts/check-melon-motion.mjs` 检查一个动作、两次咬合、平滑端点、减少动态效果；`node scripts/check-melon-arms.mjs` 检查肩部固定、手掌随瓜、肘部与图像片段；`node scripts/check-portrait-motion.mjs` 保留林加德回归；`npm run build` 编译。
